# Synonyms for search, in the Solr synonyms format: each line is one group of names that
# mean the same thing, separated by commas. Lines that start with "#" are comments.
#
# A question that mentions one name also searches for the others in its group. Every name
# also becomes a jieba user word, so it is never cut apart. After you change this file, run
# `chat-bridge ingest <folder>` again; it rebuilds the keyword index and keeps the vectors.
#
# Only names that always mean the same thing belong here. Left out on purpose:
# - a name that means different things in this data: 央行 (also inside 歐洲央行 and 日本央行),
#   BIS, Treasury, 殖利率, 政策利率, 理事會, 財政部, Committee, S&P, Nasdaq alone (Composite
#   or Nasdaq-100), 摩根 (Morgan Stanley or JPMorgan), 庫克 and Cook, 超微 (inside 美超微), 南亞;
# - a stock code that also reads as a price or a word: 2330, 2308 and the other four-digit
#   codes, TSM (inside TSMC, and a different listing), MU, Delta, Apple;
# - names that are related but not equal: 台股, 大盤 and 集中市場 against 加權指數;
#   半導體 and chip stocks against the Philadelphia Semiconductor Index; Microsoft Cloud and
#   Azure; Alphabet and Google; KPMG and 安侯建業; 外資賣超 and 外資;
# - job titles, which point at different people over time;
# - numbers, which need a conversion table, not synonyms.
# A name may not appear inside a name of another group; the file is refused if one does.
